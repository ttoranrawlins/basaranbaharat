# Başaran Baharat — Web Sitesi

1991'den beri Konak Gıda Çarşısı'nda toptan baharat üretimi ve tedariki yapan Başaran Baharat'ın tanıtım sitesi.

**Canlı site:** [basaranbaharat.com](https://basaranbaharat.com)

## Teknik Detaylar

- Tek dosyalık statik site (`index.html`) — build adımı, framework ya da bağımlılık yok
- HTML, CSS ve JavaScript aynı dosyada
- Cloudflare Pages üzerinde barındırılıyor, `main` branch'e her push otomatik deploy ediliyor

## Yerelde Görüntüleme

`index.html` dosyasını herhangi bir tarayıcıda açman yeterli, sunucu kurmana gerek yok.

## Güncelleme Yapmak

`index.html` dosyasını düzenleyip `main` branch'e push et — Cloudflare birkaç dakika içinde otomatik yayına alır.
